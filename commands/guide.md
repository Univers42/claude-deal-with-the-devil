# Guide

Subject: $ARGUMENTS

The index below is generated by `devil index --router` at the moment this command
runs, from the frontmatter of the installed tree. There is no copy to fall out of
date, which is the whole point: a router that quotes yesterday's roster is worse
than no router, because the reader cannot tell which names are real.

## The index

!`devil index --router`

Caveat: the block above is a shell injection, and whether it expanded is not
observable from here. If it came back empty or as an error, the plugin's `bin/` was
not on PATH for the shell that expanded it. Run `devil index --router` yourself (or
`"${CLAUDE_PLUGIN_ROOT}/bin/devil" index --router` when `devil` is not on PATH) and
print its output verbatim under this heading: no summary, no rewording, no dropped
column. A reworded table is the drift this command exists to remove.

## Report

The tables are the report. The committed copy in `README.md` comes from the same
functions, and `devil index --check` exits 1 the moment the two disagree, so if a
row here disagrees with the tree, the tree is the side that is right until
`devil index --write` says otherwise.
